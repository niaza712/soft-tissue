# Soft Tissue

A prototype for a holistic health coach app. Tap a part of the body to learn what it does, which foods support it, and which daily habits help. You can also ask the coach questions like "What foods should I eat to increase my fiber intake?" or "I'm at Trader Joe's, what are the healthiest frozen picks?"

**Live demo:** `https://<your-username>.github.io/soft-tissue/`

## Features

- **Tappable body map** with 8 organs: brain, eyes, lungs, heart, liver, stomach, kidneys and gut.
- **Organ guides** for each one: its role, foods that support it, daily habits and a fun fact.
- **Coach chat** with suggested questions on fiber, GLP-1 nutrition support, grocery runs and more.
- **Works on mobile and desktop**, with light and dark mode.

## How it's built

It's a single `index.html` file written in plain HTML, CSS and JavaScript, with no build step or dependencies. The illustrations are hand-drawn SVG shapes. Fonts come from Google Fonts: Bagel Fat One, Figtree and DM Mono.

In this public demo, coach answers are pre-written for the suggested questions. The concept is for the coach to be AI-powered, answering any question in the same voice.

## Run it locally

Download the repo and open `index.html` in a browser.

## Disclaimer

This is a design prototype. It gives general wellness information and is not medical advice.
